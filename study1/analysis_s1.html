Overview

This document reproduces all analyses of Study 1, a preregistered replication of Tang et al. (2025, Study 1a), and links each analysis to the preregistration (Replication Recipe) and to the draft of the paper. All numbers reported in the text below are computed in-line from the data, so the document can be re-knitted whenever the data or the analysis change.

Original study. Tang, D., Chen, J., Jiang, Q., Huang, H., & Zheng, M. (2025). How feeling loved inspires the purchase of green foods. Journal of Environmental Psychology, 102, 102523. https://doi.org/10.1016/j.jenvp.2025.102523. Original effect: d = 0.53, 95% CI [0.19, 0.87], N = 141.

Materials and preregistration: https://osf.io/vfy5g/overview?view_only=5e910d70bd6b4f669ff74c3a16c4d0bf

Preregistered hypotheses

Label Hypothesis Status
H1 Participants in the feeling-loved condition (vs. control) will have a higher intention to purchase ecological (organic) food. Confirmatory
H2 Participants in the feeling-loved condition (vs. control) will feel more loved (manipulation check). Confirmatory
H3 The effect of the manipulation on intention is positively mediated by self-esteem (labelled “self-perception” in the draft and in the data). Confirmatory extension

Criterion for a successful replication (preregistered): statistically significant (two-tailed, α = .05) differences in both intention (H1) and the feeling of being loved (H2), both in the predicted direction. Criterion for H3: self-esteem positively mediates the effect of the manipulation on intention.

Notes on correspondence between the preregistration, the script, and the draft

The following points should be resolved (or reported as deviations) before submission:

  1. Primary intention measure. The preregistration states that the three-item scale from Tang et al. (2025) is used for all tests and the remaining items are used in a sensitivity analysis. The analysis script and the draft use the six-item scale as the primary measure and the three-item scale as exploratory. This document follows the script (six-item scale as primary) but reports the three-item results right next to it in Section 5.2, so either can be designated as primary. If the six-item scale stays primary, this should be reported as a deviation from the preregistration (justified by the reliability of the three-item scale; see Section 4).
  2. Hypothesis labels. The preregistration labels the mediation hypothesis H4 in the hypothesis section and H3 in the analysis plan. This document uses H3.
  3. Sensitivity analysis excluding off-topic texts. Preregistered, but not yet implemented in the script; the written texts are removed from the anonymized data. Section 7.2 contains the code, which runs once a file with the coding of the texts is available.
  4. Sign convention. The original script used t.test() and cohen.d() with the formula interface, which computes control − experimental (hence the negative t and d for the manipulation check in the draft). Here all differences are computed as experimental − control, so positive values indicate an effect in the predicted direction. Absolute values are identical to the draft.
  5. Minimum text length. The informed consent states a minimum of 130 characters, whereas the confirmation page and the writing task require 300 characters. The Methods section should report 300 characters (the enforced minimum) and may note the discrepancy.

# Welch two-sample t-test and Cohen's d, computed as experimental (1) minus control (0)
compare_groups <- function(var, data, conf.level = .95) {
  x1 <- data[[var]][data$treatment == 1]
  x0 <- data[[var]][data$treatment == 0]
  tt <- t.test(x1, x0)                       # two-tailed Welch test
  dd <- effsize::cohen.d(x1, x0, conf.level = conf.level)
  list(
    t = tt, d = dd,
    n1 = length(x1), m1 = mean(x1), sd1 = sd(x1),
    n0 = length(x0), m0 = mean(x0), sd0 = sd(x0),
    text = sprintf("*t*(%s) = %s, *p* %s, *d* = %s, 95%% CI [%s, %s]",
                   fmt(tt$parameter), fmt(tt$statistic), fmt_p(tt$p.value),
                   fmt(dd$estimate), fmt(dd$conf.int[1]), fmt(dd$conf.int[2]))
  )
}

# Reliability: Cronbach's alpha, McDonald's omega hierarchical and omega total
reliability <- function(items) {
  om <- tryCatch(suppressWarnings(psych::omega(items, plot = FALSE)),
                 error = function(e) NULL)
  if (is.null(om)) {
    return(c(alpha = psych::alpha(items)$total$raw_alpha, omega_h = NA, omega_t = NA))
  }
  c(alpha = unname(om$alpha), omega_h = unname(om$omega_h), omega_t = unname(om$omega.tot))
}

Mediation model

The mediation model regresses self-perception on treatment (mediator model) and intention on treatment and self-perception (outcome model). The indirect effect (ACME) is tested with a nonparametric percentile bootstrap (5000 resamples) using the mediation package.

Excluding participants who wrote off-topic texts (preregistered)

Exploratory analyses (not preregistered)

Small-telescopes test (Simonsohn, 2015)

The preregistration justifies the sample size partly by Simonsohn’s (2015) small-telescopes heuristic. Here we apply the corresponding test: d33% is the effect size the original study (N = 141) had 33% power to detect. If the upper bound of the one-sided 95% confidence interval (i.e., the two-sided 90% CI) of the replication effect lies below d33%, the replication suggests the original study could not have meaningfully detected the effect. The split of the original sample into groups is not reported by Tang et al. (2025), so equal group sizes (70 and 71) are assumed.

d33 <- pwr::pwr.t2n.test(n1 = 70, n2 = 71, sig.level = .05, power = 1/3)$d

d90_6 <- compare_groups("intention",  data.complete, conf.level = .90)$d
d90_3 <- compare_groups("intention3", data.complete, conf.level = .90)$d

data.frame(
  Scale     = c("Intention (6 items)", "Intention (3 items)"),
  d         = round(c(d90_6$estimate, d90_3$estimate), 3),
  CI90_low  = round(c(d90_6$conf.int[1], d90_3$conf.int[1]), 3),
  CI90_high = round(c(d90_6$conf.int[2], d90_3$conf.int[2]), 3),
  d33       = round(d33, 3),
  Smaller_than_d33 = c(d90_6$conf.int[2] < d33, d90_3$conf.int[2] < d33)
)

star_label <- function(p) {
  if (is.na(p)) return("")
  if (p < .001) "***" else if (p < .01) "**" else if (p < .05) "*" else "ns"
}

format_r <- function(r) {
  r_rounded <- round(r, 2)
  if (abs(r_rounded) < .01) r_rounded <- 0
  sub("^0", "", sprintf("%.2f", r_rounded))
}

k <- length(var_names)
corr_table <- matrix("", k, k, dimnames = list(var_names, var_names))
for (i in seq_len(k)) {
  for (j in seq_len(k)) {
    if (i == j) {
      corr_table[i, j] <- "1.00"
    } else {
      corr_table[i, j] <- paste0(format_r(r_mat[i, j]), star_label(p_mat[i, j]))
    }
  }
}
