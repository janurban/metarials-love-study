Pilot Study 1 (Czech pilot, Love replication of Tang et al., 2025): Reproducible Analysis

This document reproduces the analyses in the Report From Pilot Study PS1 (Love Replication). It follows the original analysis script (Analysis_v3.R). Knit this file in RStudio (Knit button) or with rmarkdown::render("analysis_pilot1.Rmd") to regenerate analysis_pilot1.md in the same folder.

Data source. By default, the document downloads pilot1/data_pilot1.csv from the GitHub repository janurban/metarials-love-study. It can also read a local .csv file by passing a path with rmarkdown::render("analysis_pilot1.Rmd", params = list(data = "path/to/file.csv")).

Required packages. dplyr, readr, knitr, psych, GPArotation (psych::omega() needs GPArotation). Install them with install.packages(c("dplyr", "readr", "knitr", "psych", "GPArotation", "rmarkdown")).

# Frequency table with percentages
tab_freq <- function(x, labels) {
  f <- factor(x, levels = seq_along(labels), labels = labels)
  n <- table(f, useNA = "ifany")
  data.frame(Category = names(n), n = as.vector(n), Percent = pct(as.vector(n), length(x)))
}

1.2 Variables

In the LimeSurvey export:

  • experience[SQ001] is familiarity and experience[SQ002] is past purchase. Codes: 1 = yes, 2 = no, 3 = I do not know.
  • quiz[SQ001] is the item without text. Its instruction told participants to choose “True”, and it is not analysed (see the note in the questionnaire).
  • quiz[SQ002] to quiz[SQ009] are quiz items 1–8. Codes: 1 = true, 2 = false.
  • intention[SQ001] to intention[SQ006] are the six intention items (1–7).

Answer codes such as A1 are turned into numbers with readr::parse_number(), as in the original script.

to_num <- function(x) as.numeric(parse_number(as.character(x)))

data <- data %>%
  transmute(
    id,
    familiarity  = to_num(`experience[SQ001]`),
    pastPurchase = to_num(`experience[SQ002]`),
    emptyItem    = to_num(`quiz[SQ001]`),
    across(all_of(paste0("quiz[SQ00", 2:9, "]")), to_num),
    across(all_of(paste0("intention[SQ00", 1:6, "]")), to_num),
    gender = to_num(gender),
    age    = to_num(age),
    educ   = to_num(educ))

4. Knowledge quiz

Items 1, 3, 4 and 5 are false statements, and items 2, 6, 7 and 8 are true statements. Each correct answer scores 1. This is the same scoring as the original script, which reverses items 1, 3, 4 and 5 (3 - x) and then computes 2 - x.

quiz_items <- paste0("quiz", 1:8)
key <- c(2, 1, 2, 2, 2, 1, 1, 1)   # correct answer: 1 = true, 2 = false
quiz_text <- c(
  "1. The production of Ecological Products involves the heavy use of pesticides and artificial fertilizers to ensure high yields. (False)",
  "2. Ecological Products must comply with specific technical standards and comprehensive quality control. (True)",
  "3. Ecological Products are distinguished from conventional foods only by their price and packaging design. (False)",
  "4. The use of the Ecological Product logo is not controlled by any specific regulation. (False)",
  "5. Ecological Products may compromise on safety to achieve environmental benefits. (False)",
  "6. The Ecological Product Logo is also intended to remind people of the importance of environmental protection and preventing pollution. (True)",
  "7. The Ecological Product logo aims to strengthen harmony between humans and the natural world. (True)",
  "8. Ecological products are produced in an excellent ecological environment with minimal use of chemicals. (True)")

correct <- sweep(as.matrix(data[quiz_items]), 2, key, `==`) * 1

5.1 Descriptive statistics and floor or ceiling effects

A floor or ceiling effect would show as many participants at the lowest (1) or highest (7) possible scale mean.

scale_desc <- function(x, label) data.frame(
  Scale = label, M = fmt(mean(x)), SD = fmt(sd(x)), Min = fmt(min(x)), Max = fmt(max(x)),
  `% at floor (1)` = pct(sum(x == 1), length(x)),
  `% at ceiling (7)` = pct(sum(x == 7), length(x)),
  check.names = FALSE)
kable(rbind(scale_desc(data$intention_3item, "3 items (Tang et al., 2025, S1a)"),

5.2 Internal consistency

The original script uses psych::omega() with its defaults (three group factors, oblimin rotation). For the 3-item scale, this solution is underidentified, and psych gives a warning. The values below are the ones psych::omega() returns.

om3 <- psych::omega(Intention[, 1:3], plot = FALSE)
om6 <- psych::omega(Intention, plot = FALSE)
kable(data.frame(

6. Comparison with the report

The report gives:

  • N = 163 entered and N = 104 completed (63%).
  • Age M = 25.90, SD = 10.34; 62% with a high school diploma, 33% with a university degree; 68% women.
  • 71% had seen Ecological Products, 9% had not and 20% did not know.
  • 68% had bought them and 32% did not know.
  • Quiz: M = 7.57 correct answers, SD = 0.67.
  • 3-item scale: M = 4.61, SD = 1.13, α = 0.63, ωt = 0.68.
  • 6-item scale: M = 4.41, SD = 1.07, α = 0.80, ωh = 0.85.

Two points to check against the output above:

  1. Quiz score. The comments in the original script give M = 7.5, SD = 0.82. The report gives M = 7.57, SD = 0.67. Only one pair can match the data.
  2. Omega for the 6-item scale. The report gives ωh = 0.85, which is higher than α = 0.80. Hierarchical omega is usually lower than α. The value may be ωt (omega total), so the label “ωh” may need to be corrected.
